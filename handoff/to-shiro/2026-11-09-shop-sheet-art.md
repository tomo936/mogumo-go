# お店のシートの飾り（ポラロイドの枠・テープ）（Claude Code から、ミシェーラへ）

- 日付: 2026-11-09
- 依頼の理由: お店をタップしたときのシートを、「お店の写真をポラロイド風のシールで貼る＋自分の記録」の形にする（オーナー決定 2026-11-09）。配置のラフは `art/reference/ui/shop-sheet-D.png`、設計は `docs/superpowers/specs/2026-11-09-shop-sheet-design.md`。今は CSS の仮の見た目で作るので、仕上げの素材がほしい。

## ほしいもの
1. **ポラロイドの枠 3種**（ふつう／銀／金）。通った回数で変わる（1〜2回 ふつう、3〜9回 銀、10回〜 金）。
   - 形: 白いポラロイド。上と左右は細め、下の余白は広め（日付の手書き風の文字をアプリで重ねる）。写真の窓は横4:縦3。
   - 銀・金は、枠の縁取りやきらめきで分かる程度に（派手すぎない。明るい昼のパステルの世界観）。
   - 大きさ: 枠全体 600×640 px 前後、写真の窓の位置と大きさ（px）を添えてほしい。背景は透明 PNG、影は付けない（アプリで付ける）。
2. **マスキングテープ** 1〜2種。枠の上に斜めに貼る。160×48 px 前後、透明 PNG、少し透ける色（パステルのオレンジ・水色など）。
3. **写真が無いお店の窓の背景** 1枚。種類の模型の絵（`art/reference/shops/<種類>.webp`）を中に置く台。空色〜クリーム色のやわらかい背景。窓と同じ 4:3、透明不要。

## 置き場所
`art/ui/shop-sheet/`（frame-normal.png・frame-silver.png・frame-gold.png・tape-1.png・tape-2.png・window-bg.png）。窓の位置は同じフォルダの README.md に。
