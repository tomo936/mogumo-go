# A8 メンテナンス 設計

状態: 決定（オーナー「A で」）・実装済み／2026-11-17

## ねらい
運営がデータベースや関数を直すあいだ、使う人にアプリを触らせず、「メンテ中」と終わる予定を伝える。

## 決めたこと
- **アプリで止めるだけ（案A）**【オーナー 2026-11-17】。サーバーの書き込みの関数は直さない。
  - 案B（サーバーでも書き込みを断る）は、チェックイン・ログインボーナス・気配・ミッション・町などの SQL 関数と Edge Functions を全部直すことになり、重くて壊すおそれがあるのでやめた。
  - 残るすき: 開いたままの人は最大 1 分、書き込みができる。
- **置き場所**: 1 行だけの表 `public.app_status`（maintenance・message 200 字まで・ends_at）。アプリは表を直接読まず、関数 `maintenance_status()`（ログイン前でも読める）で読む。SQL は `supabase/migrations/0010_maintenance.sql`。
- **運営の操作**: Supabase の Table Editor で app_status の 1 行を書き換える（maintenance を true/false、文、終わる予定）。
- **確かめるタイミング**: 起動時・アプリに戻ってきたとき・開いている間 1 分ごと。
- **メンテ中の画面**: アプリの画面を外し（裏で書き込みを続けないように）、止まった絵のポコタン＋「ただいまメンテナンス中ポコ！」・運営の文・「◯時ごろ終わる予定」（日本時間。今日なら時刻だけ、別の日は日付も。過ぎた予定は出さない）・「もう一度確かめる」。
- **読めないとき**（電波・関数がまだ無い）: 止めない。前に読めた様子のまま。
- **オーナーの確認**: `?debug` で開いたときはメンテ中でも通す。

## 置き場所（コード）
- `src/maintenance/`（domain に返事の読み取りと終わる予定の文、infra に `maintenanceApi.ts`、ui に `MaintenanceGate.tsx`）。`src/App.tsx` でアプリ全体を包む。
