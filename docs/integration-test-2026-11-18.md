## 見つけたこと（直すかはオーナーと決める）

1. **【中・不具合】ビル・施設の中の店でチェックインすると、戻った一覧の「済み」が古いまま**
   - 起き方: コルティの一覧 → 店 → チェックイン成功 → 一覧に戻ると「済み 0/4」のまま、その店に印が無い（地図のピンには ✓ が付く）。一度閉じて開き直すと正しい。
   - 原因: `src/routes/MapPage.tsx` の `checkin` が成功時にお店のシートを閉じる（`setSelected(null)`）が、一覧の `building.checked` を読み直していない（「戻る」ボタンのときは読み直している）。
   - 直し方の案: 成功時に `setBuilding((b) => (b ? { ...b, checked: mapRef.current?.checked() ?? b.checked } : b))` を足す（`mapRef.current?.checkin(...)` のあと）。
2. **【小・文】ポコタンの案内の 8 ページ目が「グルメコインでガチャを引くと、新しいキャラが仲間になる」**。いまガチャは準備中（`GACHA_OPEN = false`）。
3. **【小・文】ゲストがお問い合わせを送ると「返事が必要なものは、ログインのメールアドレスにお送りします」**。ゲストにはメールアドレスが無い（送る前の画面には「ゲストには返事を送れません」と正しく出ている）。

## 環境で起きたこと（記録）
- C ドライブが満杯（空き 2.5MB）で Docker が落ち、取り込み途中のイメージが壊れた（ファイルが 0 バイト）。もぐもGO の Supabase のイメージだけ消して取り込み直した。オーナーが C を空けて 74GB に。
- 自動のブラウザは GPU が無いので遅い（地図が寄り終わるまで 20〜35 秒）。実機の速さの目安にはならない。
