# 1軒の建物にもお店のピンを付ける（短い設計メモ）

- 日付: 2026-11-09
- 決定: オーナー（「普通の1個だけの建物の上にもピン出すべきでは？」→ 案A を選択）

## 意図
SPEC S16「お店のピンには、その店のジャンルが分かる可愛いアイコン」のとおり、全部のお店にピンを付ける。今は1軒だけの建物には 3D の模型しか無く、ジャンルがピンで分からない。シロの色分けピン13種（`src/assets/pins/<種類>.png`、元は `art/pins/colored/`）がそろった。

## 考えた作り方
- **A（採用）: 地図の symbol レイヤー（MapLibre が GPU で描く）**。数百個でも軽い。基本設計（234行付近）の「お店ピンは GeoJSON source ＋ symbol layer。DOM マーカーで大量に置かない」と一致。重なりは MapLibre が自動で間引く。代わりにピンは地面の位置に立つ（3D の屋根の高さには乗らない）。
- B（不採用）: 今の HTML マーカーで近くの 40軒だけ。遠くの店のジャンルが分からない、数が増えると重い。

## 決めたこと
- 対象: いま地図に出している**1軒だけの店**（`worldLayers.ts` の `shownPlaced`＝singles）。ビル・施設のピン（`buildingPins.ts` の HTML マーカー）は今回は変えない。
- 位置: 店の模型の置き場所（`PlacedShop` の lat/lng）。ピンの先（絵の下の真ん中）を地面の点に合わせる（`icon-anchor: bottom`）。
- 絵: `PIN_ICON[kind]`（`src/shops/infra/pinIcons.ts`）を `map.addImage` で登録（`pin-<種類>`）。大きさはズームで変える（例 ズーム15で小さく、18で 36px 前後。ビルのピンと同じくらい）。
- 重なり: `icon-allow-overlap: false`（重なったら間引く）。近い店を優先したいので、`symbol-sort-key` に現在地からの距離を入れる。
- 済みの店: 今の ✓（`checkMarks.ts`）はそのまま使う（ピンと重ならないか実機で見る）。
- タップ: ピンを押したら `onPinTap([shopId])`（お店のシート）。3D の建物のタップ判定より先に効くようにする。
- 霧: 霧の中の店は今どおり出さない（霧の中 50m 以内の店は模型と同じく出す）。気配の店の伏せは今のまま（ジャンルの絵は出るが、気配のヒントでもジャンルはあいまいに出しているので可）。謎の気配の店は `mystery` の絵。
- 重ね順: 雲（霧）の層より下、自分の位置の印より下。

## しないこと
- ビル・施設のピンを symbol に移すこと（必要なら次の段で）。
- ピンを 3D の屋根の高さに乗せること。

## 追加の決定（2026-11-09 オーナー、実機を見て）
1. **1軒の店のピンを少し上に**: 地面の点から、模型の高さくらい（屋根の少し上）まで持ち上げる。ズームで持ち上げる量を変える（`icon-offset` をズームで補間。画面の真上へずらす近似でよい）。
2. **視点を指で動かしている間は、ビル・施設の HTML のピンを隠す**: ユーザーの操作（回転・拡大・ドラッグ）で動き始めたら隠し、止まったら出す。歩いてカメラが自動でついてくる動き（操作でない動き）では隠さない。symbol の1軒のピンはずれないので隠さない。
3. **ピンを出す・出さないのボタン**: 画面の上（「出典」の左あたり）に小さな丸いボタン。押すたびに切りかえ。隠すのは、お店のピン（symbol）・ビル/施設のピン・✓・施設の名前の札。気配のピン（？）は出したまま。状態はその端末に覚える（localStorage、per-viewer の便利機能）。
4. **済みの店は、ピンの右上に小さな ✓（案A）**: ジャンルのピンはそのまま、右上に緑の小さな ✓ を symbol で重ねる（ピンと一緒に動く）。1軒の店の HTML の ✓（`checkMarks.ts`）はやめる。ビルのピンはもう同じ形（右上の ✓）。
