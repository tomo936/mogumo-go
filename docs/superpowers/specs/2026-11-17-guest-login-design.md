# ゲストで始める（A3）設計メモ

2026-11-17。オーナー決定:
- ログイン方法は **Google ＋ ゲスト**（LINE・X・メールは見送り。調査 `2026-11-17-login-methods-research.md`）。
- ゲストは **遊ぶのは全部できる。感想の投稿（と通報）だけ Google が必要**。
- 「Google をつないで記録を守ろう」は **設定のボタン＋節目でひと声**。
- いたずら対策に **Cloudflare Turnstile（無料の「人間か確認」）を入れる**。

## ねらい
登録なしですぐ遊べるようにして、最初の一歩を軽くする。気に入ったら Google をつないで、記録をそのまま本登録にする。

## しくみ
- Supabase の匿名ログイン（`signInAnonymously`）。名前もメールも無いアカウントが 1 つでき、その「合いかぎ」はそのブラウザの中だけにある。アプリから見ればふつうのアカウント（同じ user_id で記録がサーバーに残る）。
- Google をつなぐ = `linkIdentity({ provider: 'google' })`。同じ user_id のまま本登録になる（自宅の保存 `mogumo.home.<userId>` もそのまま）。

## 画面
- **ログイン画面**: Google のボタンの下に「ゲストではじめる」（控えめなボタン）。押すと Turnstile の確認（たいていは自動で通る。必要なときだけ枠が出る）→ ゲストで入る → いつもの初回設定（ニックネーム → キャラ → 自宅）。
  - 小さく「ゲストの記録はこの端末だけ。あとから Google をつなげば引き継げます」。
- **設定のアカウント**（ゲストのとき）: 「ゲストで遊んでいます（記録はこの端末だけ）」＋「Google をつないで記録を守る」。ログアウトは「ゲストのままログアウトすると、この記録には二度と戻れません」と確かめてから。
- **節目でひと声**: チェックインの演出が終わったあと、ゲストのチェックイン数が 1・5・10・以後 10 ごとになったら、ポコタンの小さな窓で一度だけ「記録を守るために Google をつなごう！」（つなぐ／あとで）。同じ節目は二度出さない（端末に `mogumo.linkNudge.<userId>`）。
- **感想**: ゲストが「✎ 感想」を押すと、書く画面の代わりに「感想を書くには Google をつないでね」（つなぐ／やめる）。みんなの感想を読むのはできる。通報の「⋯」ボタンはゲストには出さない（実装で決めた。窓を出すより簡単で、サーバーでも止めている）。

## Google をつなぐとき
- つなげた → 戻ってきたら本登録。設定にメールが出る。
- その Google アカウントが、すでに別のもぐもGO のアカウントで使われていた（`identity_already_exists`）→
  「この Google アカウントには別の記録があります。そちらでログインし直すと、いまのゲストの記録は消えます」
  - 「そちらでログインし直す」→ ゲストのアカウントを消して（退会と同じ関数 `delete-account`）、Google でログイン。
  - 「やめる」→ ゲストのまま。

## サーバー（SQL 0013）
- 感想の投稿・写真の保存・通報を、ゲストには許さない（`auth.jwt()->>'is_anonymous'` が true なら断る。いまの決まりはそのままに、「制限の決まり（restrictive policy）」を足す）。
- お問い合わせはゲストも送れる（返事の宛先は空。画面で「返事が要るときは Google をつないでから」と出す）。
- そのほか（チェックイン・コイン・図鑑・ミッション・町・プレゼントなど）はゲストもそのまま。

## オーナーの作業（Supabase・Cloudflare・Vercel）
1. Supabase: Authentication → Sign In / Providers →「Allow anonymous sign-ins」をオン。「Allow manual linking」をオン。
2. Cloudflare（無料登録）→ Turnstile → ウィジェットを作る（ドメインに dev のサイトと `localhost`）→ サイトキーと秘密キーをもらう。
3. Supabase: Authentication → Attack Protection → CAPTCHA をオン、Turnstile を選び秘密キーを入れる。
4. Vercel: 環境変数 `VITE_TURNSTILE_SITE_KEY` にサイトキー（公開してよいキー）。手元の `.env` にも同じ行を足す。
5. SQL 0013 を流す。
- 注意: CAPTCHA をオンにすると、ゲストで始めるときは必ず確認が要る（Google のログインには関係しない）。

## 規約・ポリシー
- プライバシーポリシー: ゲストのとき集める情報（Google の情報は無し）、Cloudflare Turnstile（確認のために端末の情報が Cloudflare に届く）を足す。
- 利用規約: ゲストの記録は端末だけにかぎがあり、消えても戻せない、を足す。

## やらないこと
- ゲスト同士・Google のアカウント同士をまとめる（合体）機能。
- 使われなくなったゲストの自動の掃除（数が増えたら運営が Supabase の画面で消す。あとで考える）。
