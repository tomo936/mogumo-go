## できたこと
- 同じ建物の輪郭の中にお店が2軒以上あれば、ビルの模型1つにまとめる（霧が晴れて見えているお店だけでまとめる）。
- ビルの上に入っているお店のピンを少しずつずらして並べる（仮の丸。色はお店の種類）。済みのお店のピンに ✓。
- 縮小したとき、または6軒以上のときは、ピン1つ＋「済み/全部」（例 0/6）。
- ピンをタップ → そのお店のシート。ビルかまとめたピンをタップ → お店の一覧（名前の順、済みに ✓）→ 行をタップでお店のシート。

## オーナーに決めてほしいこと
1. **模型の見た目**: 見本どおりの形（クリーム色・3階・屋上のタンクと室外機・1階に白と赤のひさしの店先2つ）。ショーケースの中身は、どのお店にも合うもの（明かり・カウンター・小さなテーブル）。見本より窓の明かりが白っぽい。直したい所があれば教えてほしい。
2. **ピンの大きさ・高さ**: 今はビルの少し上に浮いていて、隣のビル同士のピンが重なる所がある。「小さくする」「ビルに近づける」のどちらがよいか。実機で見てからでもよい。
3. **ビルの多さ**: 都心では、お店のある建物の約2割がビルになる（東京駅まわりの実データ）。地図にビルがたくさん並ぶが、それでよいか。
4. **dev（開発環境）に出してよいか**: OK なら Claude Code が反映して、実機で確認してもらう。
