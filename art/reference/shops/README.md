# お店の建物の見本（シロ作・2026-11-06 ジオラマ版に全面差し替え）

地図に立てるお店の 3D 模型の設計見本。画風は「可愛いミニチュアジオラマ風（高精細・店内まで作り込み）」。
形は1軒ずつ違う（形の固定はしない）。屋根の上の大きな食べ物は無し。看板は絵だけ（文字なし）が基本。`_sheet.webp` は13種の一覧。
以前の「柔らかいマットな 3D 風」13種と、ラーメン屋 v9（赤×白）は git の履歴にだけ残る。
