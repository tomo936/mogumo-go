# Claude への依頼（下書き）2：UI/UX改善・軽量化・最終セキュリティ確認・リリース

## 1. 見た目の統一感と質
- 全体の方向性：可愛い・綺麗・かっこいいを兼ね備えた見た目にする。もぐもGOの世界観（明るい昼のグルメ：青空色＋パステル＋白基調、丸みのあるUI、もこもこ雲の霧、シールアルバム風の図鑑）は維持したまま、見た目のクオリティを誰が見ても驚く水準まで上げる
- 統一感が弱い箇所・質が低い箇所を洗い出して改善する
- 参考：X投稿（おかぴ @okapi_fukugyo）で紹介されたUI部品集5件。お手本として眺め、指示を具体化する材料に使う
  - Snapblocks（snapblocks.site）／ScrollShaders（scrollshaders.com）／AudioCN（audiocn.dev）／Animata（animata.design）／ScrollTide（scrolltide.co）
  - コードを流用する場合は、サイトごとにライセンスを確認してからにすること

## 2. 使い勝手（動線）
- チェックイン後に感想を書く動線、お店をタップしたら図鑑に飛べる動線：あった方がいいか判断し、良ければ追加する
- UXを総合的にレビューし、改善案と「あった方がいい機能」を挙げて、判断の上で追加する。オーナーの判断が要るものは判断ボードに積む
- 機能追加の検討は、リポジトリの最新仕様を正本として行うこと（実績バッジは実装済みなので、既存機能の重複提案をしない）。この検討は優先度低でよく、候補は判断ボードに提案として積む

## 3. 共有機能
- 設置場所（感想の投稿後／記録画面／その他）と共有の内容を検討し、最適な形で実装する
- 共有文にはアプリのリンク https://mogumo-go.vercel.app を入れられる形にする

## 4. 軽量化（質は落とさない）
- 電池の減りの速さと動作の重さが課題。質をなるべく落とさない最適化を行う
- 候補：描画の間引き、位置取得の間隔の見直し、霧の再描画の限定、素材ファイルの容量削減
- 実施前後の測定値を根拠として報告する

## 5. 最終セキュリティチェックとリリース
- 世界的な基準（OWASP等）と、Webアプリの基本的なセキュリティチェックを行う
- チェックは読み取り専用のレビュアー（Opus）で実施する（2026-11-19 オーナー決定）
- 2026-11-19 の総点検（security-crosscheck-20261119.md）の残件を含める：F-01 位置偽装への緩和策、H1 draw_gacha 直接呼び出し、H2 コイン水増し、H3 本番ホストでのホットペッパー／気配の動作
- 問題がなければ本番へリリースする。問題があれば直してからリリースし、結果は根拠付きで報告する
