# AI っぽさを消すための資料（2026-11-23 調査。サブエージェントが web で調べたもの）

## 要点
- **UI**: 原因は「AI を使ったこと」ではなく「誰も決めなかった既定値が残ること」。各所を「なぜこれにしたか」一文で言えるかで点検する（https://braindetox.kr/ja/posts/ai_design_tell_detection.html）。典型: 紫〜青のグラデ・既定色、書体が一種類、全部同じ角丸と影、中央寄せばかり、絵文字の印、どこも同じ余白、意味のない光やぼかし・全部に同じ動き、出どころのない数字・決まり文句（https://capitalandcompute.net/blog/fix-ai-slop-design/ ・ https://dev.to/alanwest/how-to-fix-the-ai-generated-look-in-your-frontend-1ahh）。禁止だけすると「クリーム地＋セリフ体＋テラコッタ」に流れる（Claude の画面に似る）。色は製品の素材から決め、先に短い「デザインの方針」を書いて画面ごとに照らす。
- **絵**: 正体は「整いすぎ」。一部だけ細かい、被写体と背景で光・色がそろわない、彩度が飛んだプラスチック感、影の向きの不整合、中央に対称、詰め込みすぎ（https://fyve.co.jp/ai-advisor/articles/ai-image-remove-ai-look ・ https://openart.ai/ja/blog/visual-cliches-that-scream-made-by-ai/）。統一は、画角・光の向き・形の言語・パレット・質感を書いた制作メモ→主役 1 体で確かめる→実寸・実背景で見る→承認済みを 1 枚に並べて比べる→小さな範囲ずつ差し替え（https://programminginsider.com/how-to-make-ai-game-art-look-like-it-belongs-together/）。AI の絵は「生の材料」と見て手で直す。
- **文章**: 整いすぎた構文、「重要です」「〜しましょう」、同じ主張の言い換え、語尾がそろう、接続詞の連続、無機質な丁寧さ、記号の多用（https://www.smartwatchlife.jp/60468/）。直し方は具体名・数にする、結びの決まり文句を削る、長短を混ぜる。禁止語リストは別の言い回しを生むので、公開前に照合する仕組みにする（https://fyve.co.jp/ai-advisor/articles/ai-text-style-english-calque）。ボタンは「何が起きるか」を書く。

## もぐもGO の点検表（推論を含む）
1. 配色: グラデ・既定色が残っていないか → 役割つき 4〜6 色に固定
2. 書体: 全部同じか → 見出しと本文で性格の違う丸ゴ系
3. 角丸と影: 全部同じか → 2〜3 段、影は浮く物だけ
4. 並び: 同じカードの縦並び・中央寄せばかりか → 手帳・シール帳らしい貼り方
5. 絵文字: アイコン代わりがないか → 専用の絵か文字に
6. 飾り: 意味のない光・ぼかし・同じ動き → 理由のないものは削る。動きは操作の結果に限る
7. 余白: 全部同じか → グループ間を内側より大きく
8. 絵の画風: 線・影・質感のばらつき → 画風の見本シートを作り、外れた絵を直す
9. 絵の光と色: 過飽和・光の向き違い → 光の向きを 1 つに、彩度を少し下げる
10. 絵の構図: 中央対称・詰め込み → 余白と主役を決める
11. 実寸確認: 実際の画面で形が読めるか → 細部の足し算でなく形と色で直す
12. キャラの一貫性: ポコタン・キャラの顔・色・比率 → 「変えない点」の一覧と基準画像
13. 絵の出自: 元の出力を残し、手を入れた所を記録する。AI 使用の明記の要否を決める
14. 決まり文句: 「〜しましょう！」「さあ、冒険へ！」→ 何をするか・何が起きるかを具体的に
15. 語尾と記号: 語尾がそろう・「！」や記号が多い → 長短を混ぜ、記号は意味のある所だけ
16. セリフの人格: ポコタンが一般的な丁寧語でないか → 口調・一人称・口ぐせを決めて書き直す
17. 説明しすぎ: 1 画面 1 メッセージ、半分に削る
18. 再発防止: 実際に出た AI 臭い表現の一覧を作り、公開前に照合する
