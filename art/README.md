# 素材の元データ

シロが作った素材の元データ（アプリには直接は組み込まない）。アプリで使う形に変えたものは `src/assets/` に置く。

- `characters/boy-walk/<方向>/frame-NN.png`: 男の子の歩行サイクル 8方向（背景透明 PNG、高さ 472px、各方向とも同じキャンバス・足元の位置をそろえてある）。2026-11-06 シロ
  | 方向 | コマ数 | 幅 | メモ |
  |---|---|---|---|
  | right | 28 | 293 | 透明版 v2（旧 `boy-walk-right-28f/` を置き換え） |
  | left | 28 | 293 | right の左右反転 |
  | front | 21 | 245 | |
  | back | 22 | 229 | v6。動画生成の都合で脚の横揺れが少し残る（実表示 高さ64px 程度ではほぼ見えない、オーナー判断で確定） |
  | front-right | 24 | 242 | v2 |
  | front-left | 24 | 242 | front-right の反転 |
  | back-right | 24 | 232 | |
  | back-left | 24 | 232 | back-right の反転 |
  - 幅が方向ごとに違うので、表示は「足元の真ん中」を基準にそろえる。
  - 再生速度と 待機／歩行／走行 の切り替えは SPEC §9 の速度設計（切り替え 2.0 m/s）どおり。
  - 女の子の歩行は未制作。
- `reference/`: 見た目の見本（霧・お店・雲など）。`reference/shops/` はお店の建物13種。
- `prototypes/`: 見た目の試作（Blender の手順、地図に置く試作コード）。
