# ガチャキャラ 3D素材（モデリング用リファレンス）

ガチャ開始5体＋スターター女の子の、3Dモデリング用リファレンス画像です。

- char-05-ichigo-milk-neko：05 いちごミルクねこ（★4）

- char-26-mitarashi-usagi：26 みたらし団子うさぎ（★3）
- starter-girl：スターター女の子

## ファイル構成（キャラごと）
- ポーズ4種 × 方向3種の単品PNG：stand（立ち）／walk（歩き）／run（走り）／arms（腕を広げた姿） × front（正面）／side（右向き真横）／back（後ろ）
- sheet-stand／sheet-walk／sheet-run／sheet-arms.png：3方向を横一列に並べた元シート
- 単品はすべて1600×1600・白背景。キャラの高さ1420px、足元baseline y=1500で全キャラ統一済み（3D化で寸法を揃えるため）
- starter-girl の stand 3枚は、別セットの立ち絵（3Dイメージ）から同梱

## 小物・ポーズの「正」（モデリングで守ってほしい形）
- 14 クッキーくま：右手にチョコチップクッキーを、全ポーズで常時持つ
- 26 みたらし団子うさぎ：団子串を指で握って、全ポーズで常時持つ（手が開いて串が浮く形は不可）
- 01 星降るキリン：手に何も持たない
- 05・06：小物なし
- run（走り）：片足前・片足後ろのストライド＋腕振り（両足同時上げは不可）。01の run は「腕振り版」が採用版で、sheet-run.png と単品はその版

## 申し送り
- 06 プリンしば の arms に要確認が2点あります（正面の手のひらが正面を向いている点／横向きのリュック側面に参照にないベージュ模様）。オーナー判定はまだです。
