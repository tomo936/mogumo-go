# A11 近くのお店の一覧 設計（2026-11-16 オーナーと決定）

## 決まったこと（オーナー）
- **ボタンの場所**: 右上の方位磁針の**下**に丸いボタン（扇の中には入れない。「扇はいやだ」）。
- **徒歩圏内だけ**: 晴らしたお店が無限に出てくるのを避ける。範囲は `WALK_RADIUS_M` = 800m（徒歩約 10 分。リーダーの案、オーナーが変えてよい）。自分の今いる場所から測る（カメラが離れた所を見ていても）。
- **ジャンルで絞り込み**: 一覧の上の札（「すべて N」＋ジャンルごとの数、数の多い順）。同じ札をもう一度押すと解除。

## リーダーが決めたこと（要確認）
- 全画面の一覧（設定・記録と同じ手帳の見た目）。行 = 種類の絵・店名・種類名・済みの印・距離（10m 単位）。近い順。
- 出すのは晴れた場所のお店と、霧の中でも 50m 以内のお店（S1 のまま）。
- 正体を伏せたままの気配の店は出さない（名前が分かってしまうため）。
- お店を押すと一覧を閉じ、お店へカメラを寄せてお店のシート（図鑑の「地図で見る」と同じ。シートを閉じたら自分に戻る）。
- ボタンの絵は仮（線の店アイコン、橙の丸）。ミシェーラの丸ボタンの絵ができたら差し替える。
