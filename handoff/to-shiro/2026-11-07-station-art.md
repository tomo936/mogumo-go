# 駅舎の見本（小さな駅の模型と、大型施設に添える駅の飾り）

- 日付: 2026-11-07（Claude Code から）
- 設計: `docs/superpowers/specs/2026-11-07-large-facility-design.md` §2

## 用途
- 駅の建物にお店があるとき、「ここは駅」と分かるように地図に置く模型の見本。Claude Code が Blender で同じ形の模型を作る。
- 使い方は2つ: ①小さい駅（お店が2〜5軒）はこの駅舎の模型をそのまま置く。②東京駅・新宿駅のような大型施設には、実際の形の立体の上（駅の点の位置）に、この駅舎を小さく添える。

## 描いてほしいもの
- 小さなかわいい駅舎を、ななめ上から見た絵（これまでのお店の見本と同じ角度）。
- 入れてほしい要素（おまかせで足し引きしてよい）: 三角屋根、屋根の上か正面の丸い時計、改札の入口（ひさし付き）、ホームの屋根が少し見える、ベンチや植木などの小物を少し。
- 入れないもの: 駅名・看板の文字・実在の鉄道会社のロゴや色の組み合わせ（どの駅にも使うため）。
- 画風: 「明るい昼のグルメ」。これまでの見本（`art/reference/shops/`、特に `building-multi.png`・`shop-other-restaurant.png`）とそろえる。
- サイズ: 1600×1600px 前後、背景は無地の水色。
- 置き場所: `art/reference/shops/station.png`
- できれば、使った色の番号（#rrggbb）を末尾にメモしてほしい。

## 優先度
- 13種のピンのアイコンより後でよい。届くまでは Claude Code が仮の駅舎で作っておく。
