# UI/UX 大規模見直しの計画（2026-11-23。B-18 で決定）

方針・評価の正本: `docs/uiux/2026-11-23-evaluation-and-plan.md`。点検のページ: https://claude.ai/artifact/9tvo5bWTtnsotLuQkyMmH8
決まり: 色の方向 A（クリーム・茶色の手帳風を土台。B-16）／芯は「旅の手帳」／ポコタンのセリフ（文字）は入れてよい・音の声は追加しない／キャラのイラストの画風の違いはいったん許容（オーナー）／絵は ChatGPT、Claude は画風の見本・指示文・仕上げ・実寸比較（B-17・B-20）／先に作る機能は ◎ の 3 つ（スタンプから感想へ・お店から図鑑へ・共有。B-19）／ガチャの 3D はこの見直しのあと（B-15）。

## 進め方（毎段の決まり）
1. 変える前の画面を撮る（無ければ）→ 変える → 同じ手順で撮る → 並べて見比べる。
2. テスト役（tester）に差分のレビューを頼む（既存の動きを壊していないか）。
3. `npm test`・`npx tsc -b`・`npm run lint` を通す。
4. 問題が無ければ dev に出し、判断ボードに「自動で決めた」か決定済みとして記録する。
