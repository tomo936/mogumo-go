# 「その他（ジャンル不明）」のお店のピンの絵（Claude Code から）

- 日付: 2026-11-09
- 依頼の理由: ジャンルが分からないお店のピンに、今は謎の気配と同じ `pin-mystery`（紫の「？」）を使っている。オーナーの実機確認で「気配のアイコンと一緒はだめ」となった（オーナー決定 2026-11-09）。気配の「？」とはっきり見分けられる「その他」のピンがほしい。

## ほしいもの
- 内容: 「ジャンルは分からないけど、ごはん屋さん」と分かる絵。例: フォークとナイフ、またはクローシュ（ドーム型のカバー）。`art/pins/facility.png`（施設ピンの絵）と似すぎないように。
- 形: 今の色分けピン13種（`art/pins/colored/pin-<種類>.png`）と同じ作り。白い丸の中に絵、まわりに色の枠、下に先。512×512、背景透明 PNG。
- 枠の色: 13種と、謎の気配の紫（`pin-mystery.png`）のどれとも違う、落ち着いた色（例: グレーがかった青、ミントグレーなど。おまかせ）。
- 画風: 13種とそろえる（線の太さ・影・色味）。
- 置き場所: `art/pins/colored/pin-other.png`（画像本体をセッション経由で送る場合は、Claude Code が置く）。

## 補足
- お店の種類をこのあと増やす相談をオーナーとしている。増える種類のピンは、決まったら別の依頼にまとめる。
- 届くまでは、アプリでは仮に「白い丸に🍽」を出す。
