# アバター3D化の相談と試行（男の子で色付き生成ができるか）（Claude Code へ、ミシェーラから）

- 日付: 2026-11-09
- 種別: 相談＋試行の依頼。本採用の決定ではありません

## 背景
- オーナーが2Dコマ方式（8方向×21コマ）の限界を感じ、アバターの3D化を検討しています。
- 調査の結論: 3D化で「方向ごとの同一性ドリフト／背面の脚の横揺れ／速度連動の滑らかさ」は構造的に解消します。ただし立ち絵の顔・可愛さの完全再現はどのルートでもできません。
- オーナーは自分でツール（VRoid等）を操作しない前提です。エージェントだけで回るルートを優先します。人型をBlenderで一から生成する方式は、質の天井が低いため採りません。生成はAIモデルに任せます。
- 実績（ミシェーラ側で試行済み）: Hunyuan3D-2 公式デモ（HuggingFace Space）でガチャキャラ「クッキーくま」の形を生成。約1分で、シルエット・目鼻口の凹凸・クッキー・リュック・しっぽまで形状は再現しました。ただしデモ側はテクスチャ合成が無効で無地の灰色でした。色付きは未検証で、今回確かめたいのはそこです。

## 試してほしいこと（今回の範囲はここまで）
1. PCのComfyUIに Hunyuan3D-2 のワークフロー（テクスチャ付き、low_vram、RTX 3060 12GB前提）を用意する。導入物は公式・実績のある出所のものだけにしてください。
2. スターター男の子の立ち絵（リポジトリの `src/assets/characters/starter-boy.webp`）から、テクスチャ付きGLBを生成する。数回試行して最良の1体を選ぶ。
3. 結果を `handoff/to-shiro/` へ返信する。含めてほしいもの:
   - 正面・横・背面のレンダリング画像
   - GLBの置き場
   - VRAM使用量と生成時間
   - 色・顔の再現度についての所感
   - 詰まった点（あれば）

Mixamoでのリグ・歩行アニメ・アプリへの実装は、今回の結果を見てから別途相談します。
