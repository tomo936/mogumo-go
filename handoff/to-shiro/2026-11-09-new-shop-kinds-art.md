# お店の種類を4つ増やす：ピンの絵と建物の見本（Claude Code から、ミシェーラへ）

- 日付: 2026-11-09
- 決定: オーナー（2026-11-09。実データ調査で「その他」になる店が地図の店の 45% と分かり、種類を増やすことにした。ピンも 3D の模型も増やす）
- 調査の要点: 経堂・新宿・東京駅・三軒茶屋の 1km で、牛丼・丼 49軒、ハンバーガー・ファストフード 約46軒、アジア・エスニック 約45軒、粉もの 約19軒が「その他」になっていた。

## 増やす4種類（ファイル名に使う名前）
| 名前 | 種類 | 入るお店の例 | 建物のイメージ（案。おまかせで可） |
|---|---|---|---|
| donburi | 牛丼・丼もの | 吉野家・松屋・すき家・なか卯・天丼の店 | オレンジ系ののれん・カウンター越しの丼、気軽な食堂 |
| burger | ハンバーガー・ファストフード | マクドナルド・モス・ケンタッキー・サブウェイ | アメリカンダイナー風、赤×黄、大きな窓 |
| ethnic | アジア・エスニック | タイ・ベトナム・韓国料理など（インド・ネパールは今のカレー屋に入れる） | 屋台風のひさし、色とりどりの提灯や布、植物 |
| konamon | 粉もの | お好み焼き・もんじゃ・たこ焼き・鉄板焼き | 鉄板の見える下町の店、のれん、たこ焼きの屋台風の窓口 |

## ほしいもの（1種類につき2つ）
1. **ピンの絵**: 今の色分けピン13種（`art/pins/colored/pin-<種類>.png`）と同じ作り。512×512、背景透明 PNG。白い丸の中にジャンルの絵（丼・ハンバーガー・生春巻きやフォーなど・お好み焼きやたこ焼き）、まわりに色の枠、下に先。枠の色は、今の13種と「その他」（別依頼 `2026-11-09-other-pin.md`）・謎の気配の紫と重ならない色。
   - 置き場所: `art/pins/colored/pin-<名前>.png`
2. **建物の見本の絵**: 今の見本（`art/reference/shops/<種類>.webp`、`_sheet.webp` が一覧）と同じ画風。「かわいいミニチュアジオラマ風」、斜め上から見た1軒、背景は白か透明。形は1軒ずつ違う・屋根の上に食べ物は乗せない・看板は絵だけ（文字なし）という今の決まりにそろえる。これを元に Claude Code が Blender で模型を作る。
   - 置き場所: `art/reference/shops/<名前>.webp`（または .png）

## 補足
- 画像本体をセッション経由で送る場合は、Claude Code がその場所に置く（送るときは、Claude Code が作業していない時に送ってもらえると確実に保存できる）。
- 届くまで、この4種類のお店は今どおり「その他」で出る。
