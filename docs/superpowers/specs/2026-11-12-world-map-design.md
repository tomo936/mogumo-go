# ワールドマップ＋検索 設計（2026-11-12）

状態: オーナー承認済み（見本 `.superpowers/preview/worldmap/` の 4 画面に「いいよ」）

## 目的
行った所を日本全体で一目で見て、そこへ飛んで振り返れるようにする。地名の検索で、行っていない場所にも飛べる（ただし霧の中は見えない）。

## オーナーの決定
- 日本地図の「行った所」は **町ごと**（案A）。クリア＝橙、途中＝うす茶。
- **記録から開く別の画面**。
- 飛んだ先は「見るだけ」。チェックインはできない。「今いる場所に戻る」がある。
- **仕様 S1 を守る**: 飛んだ先でも、行っていないお店は出さない。出すのは晴れた所と、行ったお店（✓）だけで、ほかは雲。
- 見た目は見本どおりで、品質は高く。

## 非目標（やらないこと）
- 飛んだ先でのチェックイン。行っていないお店や気配を出すこと。
- お店の名前での検索。
- 飛んだ先の 3D の建物（v1 は見本どおりの真上からの平らな地図）。

## 画面と流れ
1. **記録**（`Record.tsx`）: 「ワールドマップ」ボタンは**地図に重ねない**（オーナー 2026-11-12「邪魔だから地図の上か下に」）。タブと地図のあいだの行の右寄せに置く。押すとワールドマップを全画面で重ねて開く。
2. **ワールドマップ**（日本全体）
   - アプリと同じテーマ（`STYLE_URL`・`MAP_THEME`・`themeStyle`）を使う。日本全体が入る寄りで開く（zoom 4〜11、指で動かせる）。
   - 遠くでは道・境界・文字を消す（見本と同じ）。
   - 行った町に旗の印（`TownIcon`）と町名の札を付ける。画面の上で近い印は、数の丸にまとめる。丸を押すと寄る。
   - 上に「←」（記録へ戻る）と検索欄。下に帯「行った町 N ｜ クリア M」。
3. **検索**
   - 2 文字以上を打ち、手が止まってから 0.4 秒後に国土地理院の住所検索（`https://msearch.gsi.go.jp/address-search/AddressSearch?q=`、キー不要、CORS 可を確認済み）を呼ぶ。
   - 候補は最大 8 件。候補を押すとその場所へ飛ぶ（zoom 15）。
   - 候補の下に出典「地名検索: 国土地理院」を出す。
   - 失敗したら「探せませんでした」。送るのは打った言葉だけ。
4. **見るだけ**（飛んだ先）
   - 真上からの地図に、本物の雲の霧を出す。晴れる所は記録の地図の「今」と同じ（チェックインのマス・自宅のまわり・クリアした町）。
   - 行ったお店のピンに ✓ を付ける。押すとお店のシートを開く。シートは見るだけで、行った回数と距離を出し、チェックインのボタンは無い。
   - 上の帯は「👀 見ているだけ／<町名 or 地名>・チェックインはできません」と ×（ワールドマップへ戻る）。
   - 下に「📍 今いる場所に戻る」。押すとワールドマップと記録を閉じ、ふだんの地図へ戻る（ふだんの地図は動かしていないので、そのまま自分の位置）。
   - 町の印から飛んだときは、町の四角（bbox）が入る寄りにする（13〜17 の範囲に収める）。

## 作り（リーダーの判断）
- **新しいフォルダ `src/world/`**
  - `domain/cluster.ts`: 画面の座標で近い印をまとめる。純粋な計算。
  - `domain/gsi.ts`: 検索の返事を読む。
  - `domain/box.ts`: 町の四角の中心と寄りを決める。
  - `infra/townBoxes.ts`: `towns` の `min_lat`・`max_lat`・`min_lng`・`max_lng` を `.in()` で読む。形は読まない（軽い）。
  - `infra/placeSearch.ts`: 地理院への fetch。
  - `ui/WorldMap.tsx`、`ui/PlaceView.tsx`、`ui/world.css`。
- **データは記録がもう持っているものを渡す**: 町の一覧（`TownList` の状態）と、記録の `cells`・`visits`・`towns`。新しいサーバーの関数や SQL は作らない。
- **見るだけの地図は `RecordMap` を使い回す。** 足すのは次の 2 つの任意の引数だけ。
  - `focus?: { center; zoom }`
  - `onPinTap?(shopId)`
  - `t` は今の時刻にする。行ったお店は全部ピンにする。雲と晴れの計算を二重に持たないためである。
- **お店のシート**: `ShopSheet` に任意の `viewOnly?: boolean` を足し、チェックインのボタンと誤りの文を出さない。行った回数は今の `Visits` の形で渡す。
- **画面の重ね方**: ワールドマップは `Record` の中から全画面で重ねる。`Record` の `onClose` を「今いる場所に戻る」に使う。ルートは増やさない。
- 新しい部品の見た目（ボタン・検索欄・帯・候補・戻るボタン）は、見本の `wm.css` に合わせる。

## 守ること
- 依存の向きは ui → infra → domain。domain は何も import しない。
- 打った言葉以外は外へ送らない（自宅・位置は送らない）。
- テストで確かめること:
  - 印のまとめ
  - 検索の返事の読み取り（壊れた返事を含む）
  - 町の四角の寄り
  - ShopSheet の viewOnly でボタンが無いこと
  - 記録からワールドマップを開いて閉じる流れ

## 残り・リスク
- 地理院の住所検索は、公式の一覧に載った API ではない（地理院地図が使っているもの）。止まったら、検索欄に「探せませんでした」と出るだけで、ほかは動く。
- 町の数が多い人（数百）でも、四角だけ読むので軽い。
