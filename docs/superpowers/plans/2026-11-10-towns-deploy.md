# 町のクリア・コンプリート 公開（デプロイ）の手順（本人用）

アプリ側はもう開発用のサイト（`mogumo-go-dev.vercel.app`）に入っています。町を実際に動かすには、Supabase の **開発用プロジェクトに、SQL（0005）・境目のファイル・関数 `towns` を置く** 必要があります。下の順に進めてください（15〜20分ほど）。

> **重要: 必ず開発用プロジェクト `mogumo-go-dev` で作業してください。本番のプロジェクトは使いません。** 画面の上のほうのプロジェクト名が `mogumo-go-dev` になっていることを、毎回確かめてください。

> 置く前でも、アプリは壊れません（チェックインは今までどおり。記録の「町」の所に「読み込めませんでした」と出るだけ）。順番は 2 → 3 → 4 のとおりに。

## 1. 開発用プロジェクトを開く
1. ブラウザで Supabase（supabase.com）にログインする。
2. プロジェクト一覧から **`mogumo-go-dev`** を選ぶ。

## 2. SQL（0005）を流す
1. 左のメニューから **SQL Editor** を開き、**New query** を押す。
2. パソコンで `supabase/migrations/0005_towns.sql` を開き、**中身を全部コピー**して貼る。
3. **Run** を押す。「Success」と出れば OK（何度流しても大丈夫な作りです）。
4. 赤いエラーが出たら、文面をそのまま Claude Code に見せる。

## 3. 境目のファイルを置く（全国分 1,025 個・合計 59MB）
ファイルはパソコンの中にもう出来ています。場所は、エクスプローラーのアドレス欄に次を貼ると開きます。

```
\\wsl.localhost\Ubuntu\home\otosa\mogumo-go\.towns-out
```

中に **`g`** というフォルダが1つあります（中身は `index.json` と `◯◯_◯◯.json.gz` が 1,024 個）。

1. 左のメニューから **Storage** を開き、**New bucket** を押す。
2. 名前は **`towns`**。**Public bucket はオフのまま**（非公開）。ほかはそのままで作る。
3. 作った `towns` を開く。
4. エクスプローラーの **`g` フォルダごと**、ブラウザの画面へドラッグして落とす（フォルダの中身ではなく、フォルダそのもの）。
5. 上がり終わるまで待つ（数分）。終わったら `towns` の中に `g` があり、その中に `index.json` が見えれば OK。
6. 途中で止まった・数が足りないときは、もう一度同じように落とす（同じ名前は上書きを選ぶ）。うまくいかなければ Claude Code に言う。

> **全国分がそろってから置く**（`g/index.json` は全県分が入ったものだけ。一部の県だけの一覧を置くと、ほかの県のお店が「町なし」と覚えられてしまいます）。

> ポリシー（Policies）は何も足しません。読むのは関数だけで、アプリやほかの人からは読めないままにします。

## 4. 関数 `towns` を新しく置く
1. 左のメニューの **Edge Functions** → **Deploy a new function** → **Via Editor**。
2. **先に、関数の名前を `towns` に変える**（変えないと仮の名前で置かれます）。
3. `index.ts` に `supabase/functions/towns/index.ts` の中身を全部貼る。
4. ファイルを足して（Add file）、**`core.ts`**（`supabase/functions/towns/core.ts`）と **`tiles.ts`**（`supabase/functions/towns/tiles.ts`）を貼る。3つそろっていることを確かめる。
5. **Verify JWT** がオン。Secrets（キー）は何も足さない。
6. **Deploy function**。

## 5. iPhone で確かめる
1. アプリを開き直す（設定のバージョンの番号が新しくなっていること）。
2. 下のラーメンの丸 → **記録** を開く。少し待つと「町のクリア・コンプリート」に、今までに行った町が並ぶ（初めは「数えています…」→ 開き直すと「3 / 12」のような数とゲージ）。
3. すでに半分以上回っていた町は、ここで「クリア」になり、コインが +100 される（1つの町につき1回だけ）。
4. 地図に戻ると、クリアした町の霧が町の形で晴れている。
5. まだクリアしていない町でチェックインして半分に届くと、数秒後に上に「◯◯ クリア！ +100」の帯が出て、町の霧が晴れる。
6. スプラッシュと設定に「町の境目: …（総務省統計局・e-Stat）を加工して作成」と出ている。
7. 気になったことは、画面を撮って Claude Code に送る。

## うまくいかないとき
- 記録の町の所が「読み込めませんでした」のまま: 手順 4 の関数の名前が `towns` か、ファイルが3つあるかを見る。
- 町が1つも出ない: 手順 3 の `towns` バケットの中が `g/index.json` の形になっているか（`g` の中に `g` が入っていないか）を見る。
- それでも分からなければ、Edge Functions → `towns` → **Logs** の赤い行を撮って送る（ログには人・お店・町の番号や場所は出ません）。

## あとで（本番に出すとき）
同じ 2〜4 を本番のプロジェクトでも行う。境目のファイルは同じ `.towns-out/g` を使う。作り直すときは `node scripts/towns/build.ts --work .towns-work --out .towns-out`（全国で 20分ほど）。
