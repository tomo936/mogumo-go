# ガチャ（A15）の置き方（オーナーの作業）

2026-11-17。アプリは dev に反映済み。サーバー側に 1 つだけ作業がある。

## 1. dev の Supabase で SQL 0014 を流す
1. Supabase（dev のプロジェクト）→ SQL Editor → New query
2. `supabase/migrations/0014_gacha.sql` の中身を全部貼って Run
3. 「Success」と出れば OK
4. 続けて `supabase/migrations/0015_rename_kirin.sql`（01 の名前を「星降るキリン」にそろえる。流さなくても問題なし）も同じように Run（0014 をまだ流していなければ、0014 だけで新しい名前になる。流しても害はない）

流す前でもアプリは動く（ガチャを引くと「まわせませんでした」と出るだけ。キャラ一覧は最初の 2 人だけ）。

## 2. 確かめること（iPhone）
- メニューの「ガチャ」→ コインが 100 以上あれば「1回まわす」が押せる → 鍋の演出 → キャラが出る
- 左上のキャラを押す → キャラ一覧 → 出たキャラを選んで「このキャラにする」→ 左上の絵と地図のキャラが替わる（3D が無いキャラは絵の立ち姿）
- 試しにコインを増やしたいときは、プレゼント（Table Editor の `presents`）で自分にコインを送る

## 3. あとで（本番に出すとき）
- 本番の Supabase にも 0014 を流す（0009〜0013 と一緒に）。

## 運営の操作
- ガチャに入れるキャラを増やす: Table Editor → `characters` → `in_pool` を true に（アプリの `src/gacha/domain/characters.ts` の `IN_POOL` も同じにする）。
