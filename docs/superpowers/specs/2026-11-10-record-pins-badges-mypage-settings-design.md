## 1. 記録の地図に、行ったお店のピン

- スライダーの日付までに行ったお店を、地図の上にピンで出す。絵は地図と同じ種類のピン（`src/assets/pins/<種類>.png`）を小さくしたもの。
- **スライダーの日（その1日）に行ったお店**は大きく出し、ぽんと弾む。それより前の日のお店は小さく、少しうすく。→ スライダーを動かすと「この日はここに行った」が地図で分かる。
- その日のピンには、その日に回った順の番号（1, 2, 3…）を付ける（リーダーの判断。はしごの順が見える）。
- ‹ › のボタンは「1週ずつ」をやめて、**行った日から行った日へ跳ぶ**（リーダーの判断。行っていない日に止まっても地図が変わらないため）。スライダーを指で動かすのは今のまま。
- ピンを押すと、店名と行った日の小さな札が出る（押したら閉じる）。
- データ: 今の `loadRecord` の shops の読みに `lat, lng` と時刻（`checked_in_at`）を足す。新しい表やサーバーの処理は要らない。
- 同じお店に何度も行ったときは、ピンは1つ。大きさと番号はスライダーの日に行ったかどうかで決める。

## 2. 実績（記録の中のタブ）

- 記録の画面の上に「きろく｜じっせき」のタブ。実績のタブはバッジの並び。
- **計算は手元で行う**（リーダーの判断）: チェックインの履歴・お店の種類・晴れたマス・自宅から、取れたバッジと取れた日を計算する。サーバーへの保存（`user_badges`）は、まだしない。他の人に見せる・通知を出すなどの必要が出たら Edge Function で保存する（DB の表はもうある）。
- 取れていないバッジは、灰色のシルエットで条件だけ見える（「？」で隠さない。目標になるように）。ただし「ひみつ」の実績は条件も隠す（「？？？」）。
- バッジを押すと、名前・条件・取った日・あと何回、が出る。

### 2.1 ジャンルの段（18種類 × 3段）
- 数えるのは**行った回数**（同じ店に2回で2回。1日1回まで＝チェックインの決まりと同じ）。
- 段: **3回 =「〇〇好き」（銅）／ 10回 =「〇〇名人」（銀）／ 30回 =「〇〇マスター」（金）**。
  例: ラーメン好き → ラーメン名人 → ラーメンマスター。カフェ好き → カフェ名人 → カフェマスター。
- 「その他（mystery）」は「なぞ好き → なぞ名人 → なぞマスター」。

## 3. マイページ（全画面）

- 上: キャラの絵（大きく）、ニックネーム（鉛筆で変更。10文字まで・重複OK＝S15）、Lv と「次の Lv まであと◯軒」のバー。
- 数字のカード: 行ったお店・晴れた広さ・実績の数・グルメコイン（`coin_ledger` の合計）。
- 飾った実績: 最近取ったバッジ3つ（押すと実績タブへ）。
- 自宅: 「自宅の場所を変える」（S15「変更はマイページから」）。押すと初回設定の自宅の画面（現在地ボタン＋地図で微調整）を使って保存し直す。保存先は今と同じ端末の中だけ。
- キャラの切りかえはガチャができてから（今は出さない）。

## 4. 設定（全画面。今の中身を整える）
