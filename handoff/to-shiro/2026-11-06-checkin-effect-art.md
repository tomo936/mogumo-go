# チェックインの演出の素材 4種

- 依頼日: 2026-11-06
- 背景: チェックインの演出（紙ふぶき → 完了の帯 → お店のチェックの印 → 霧の波）は、いまコードで作った試作。もっとクオリティの高い可愛い感じにするため、下の素材を頼む。届いたら差し替える
- 共通: 「明るい昼のグルメ」、パステル、白基調、背景透明の PNG
- 置き場所: `art/checkin/<名前>.png`（元データ）。アプリ用に変えたものは Claude Code が `src/assets/` に置く
- 仕様の出どころ: `docs/superpowers/specs/2026-11-06-hotpepper-checkin-design.md` 9章

## 素材

- **紙ふぶき**: 3〜4種の小さな形（丸・星・リボン・もぐもGO らしい食べ物の欠片）。各 64×64px。
- **完了の帯の飾り**: 帯の左に置くチェックの丸、128×128px。帯そのものは CSS で作る。
- **コイン**: グルメコインの絵、64×64px（帯の「+30」の横、のちにガチャでも使う）。
- **ピンのチェックの印**: 建物の上のピンに重ねる小さな印、64×64px。
