# handoff — シロ ⇄ Claude Code の連携フォルダ

このフォルダが、シロ（Muse）と Claude Code の情報連携の正本です。
セッションのチャット経由の受け渡しは行わず、依頼・素材・報告はすべてここを通します。

## 置き場所

- `to-claude/` — シロ → Claude Code の依頼。1依頼 = 1ファイル。
- `to-shiro/` — Claude Code → シロ の依頼（素材の制作依頼など）。1依頼 = 1ファイル。
- `LOG.md` — 受け渡しと完了の履歴。両者が追記する。

## 依頼ファイルの形式

- ファイル名： `YYYY-MM-DD-<内容のslug>.md`
- 先頭に状態を書く： `状態: 未対応` / `対応中` / `完了`
- 本文： 依頼内容、仕様、期限や前提があればそれも。
- 素材ファイルそのものは `art/` など所定の場所に置き、依頼文にはそのパスを書く。
  （このフォルダには大きなバイナリを置かない）

## 運用

- Claude Code は、セッション開始時に `to-shiro/` の「未対応」と、この README を確認する。
- シロは、作業前に `to-claude/` と `LOG.md` の状態を確認する。
- 依頼に対応したら、状態を更新し、`LOG.md` に1行残す。
- 仕様の正本は従来どおり `docs/SPEC.md`。このフォルダは受け渡し専用で、仕様をここに書かない。
