# お知らせ・プレゼント（A7）設計メモ

2026-11-17。オーナー決定: ボタンは案A（右の「近くのお店」の下に手紙の丸ボタン）。

## ねらい
運営（オーナー）からの連絡と、お詫び・記念のコインを、アプリの中で届けられるようにする。
運営の道具は Supabase の画面（Table Editor）だけ。管理画面は作らない。

## 決まり
- **お知らせ**: 表 `notices` に運営が 1 行足す（題・本文・出す期間）。期間内のものを新しい順に最大 30 件。
  - 読んだかどうかは端末ごと（localStorage `mogumo.noticesRead.<userId>` に読んだ番号の一覧）。お知らせを開いたら、そのとき見えている分を読んだことにする。
- **プレゼント**: 表 `presents` に運営が 1 行足す。中身は**グルメコインだけ**（1〜10,000 枚）。
  - 宛先: `user_id` が空なら全員、入っていればその人だけ。
  - 期限 `expires_at`（既定は足した時から 30 日）。期限を過ぎたら受け取れない。
  - 受け取りは SQL 関数 `claim_present(id)` で **1 人 1 回だけ**。コインは `coin_ledger` に `reason = 'present'` で、受け取りの記録と同じトランザクションで書く（ログインボーナスと同じ形。`auth.uid()` だけを見る）。
  - 一覧に出すのは: 期限内で受け取っていないもの＋受け取り済み（30 日まで、薄く「受け取り済み」）。
  - 「全員」の宛先は、期間中にアプリを開いた人なら、あとから始めた人も受け取れる（簡単さを優先。困ったら期間を短くする）。
- **画面**: 1 つの画面にタブ「お知らせ｜プレゼント」。右から滑って出る手帳風（近くのお店の一覧と同じ見た目）。勝手には開かない。
  - 開いたときのタブ: 受け取っていないプレゼントがあればプレゼント、なければお知らせ。
  - 受け取ると「ちゃりん」（coin の音）、ボタンが「受け取り済み」に変わり、左上のコインの数字を読み直す。
- **赤い点**: 手紙のボタンの右上に、未読のお知らせか受け取っていないプレゼントがあれば出す。
  - 地図に入ったとき・アプリに戻ってきたとき・画面を閉じたときに読み直す。
- **ボタン**: 右の「近くのお店」ボタン（`.hud-nearby`）の下、同じ大きさ・色の丸に線のアイコン `mail`。新しい絵は要らない。

## 案（考えたもの）
- ボタンの置き場: A 右の丸ボタン（採用。絵が要らず、赤い点が常に見える）／B 下の扇に足す（扇を開かないと点が見えない・ミシェーラの絵が要る）。
- 読んだ記録: 端末ごと（採用。表が増えない）／サーバーに保存（機種変更で引き継げるが、お知らせは数が少なく大事でない）。
- プレゼントの中身: コインだけ（採用。ガチャがまだ無いのでアイテムは配れない）。

## サーバー（SQL 0011_inbox.sql）
- 表 `notices`（`notice_id` 連番, `title`, `body`, `starts_at` 既定 now, `ends_at` 空なら無期限, `created_at`）
- 表 `presents`（`present_id` 連番, `user_id` 空=全員, `title`, `message`, `coins` 1〜10000, `starts_at` 既定 now, `expires_at` 既定 now+30日, `created_at`）
- 表 `present_claims`（`present_id`, `user_id`, `claimed_at`。主キー 2 つ）
- `coin_ledger` に `present_id` の列と理由 `present` を足す。`(user_id, present_id)` は一意（2 重の受け取りをもう一段で止める）。
- 関数（どれも security definer・`auth.uid()` だけを見る・anon は使えない）
  - `my_notices()` … 期間内のお知らせ
  - `my_presents()` … 自分宛て（全員宛て含む）の、期限内か受け取り済みのもの＋受け取ったか
  - `claim_present(p_present_id)` … 受け取る。返す: もらった枚数（受け取れないときは 0 と理由）
- 3 つの表はアプリから直接は読み書きできない（関数だけ）。運営は Table Editor（RLS の外）で足す。

## 残すこと
- お知らせの本文の装飾（リンク・画像）は無し。文字だけ（改行はそのまま出す）。
- 通知（プッシュ）は無し。
