## 問題なしと確認した所
- 全テーブルで RLS。本人以外は読めない／書き込みはサーバーの関数だけ。
- security definer の関数は search_path 固定・public/anon から取り上げ済み・本人は auth.uid() で決める。p_user を受け取る関数は service_role だけ。
- 二重受け取り・競合（チェックイン・コイン・プレゼント・ログインボーナス・ガチャ）は一意制約とロックで防いでいる。
- ゲストの制限（感想・写真・通報）、写真の置き場の権限、期限付き URL。
- Edge Functions はトークンの確認・入力の検証・エラーで中身を漏らさない・位置をログに出さない。退会は本人だけ。
- XSS の入口なし。キー: ブラウザは anon だけ、ホットペッパーのキーはサーバーだけ。check-secrets 相当を追跡中の全ファイルにかけて 0 件。
