# ワールドマップ＋検索 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 記録から開く日本地図（行った町の旗・地名検索）と、飛んだ先の「見るだけ」地図を作る。

**Architecture:** 新しい機能フォルダ `src/world/`（domain＝計算、infra＝Supabase の町の四角・地理院の検索、ui＝画面）。データは `Record` が既に持つもの（町の一覧・cells・visits・towns）を渡し、サーバーは変えない。見るだけの地図は `RecordMap` に任意の引数を足して使い回す。

**Tech Stack:** React 19 / TypeScript 7 / MapLibre GL / Vitest + Testing Library。

**Spec:** `docs/superpowers/specs/2026-11-12-world-map-design.md`。見た目の正解は `.superpowers/preview/worldmap/`（`main.tsx`・`wm.css`）と撮った見本 4 枚。

## Global Constraints
- CLAUDE.md のツールチェーンの注意（`import type`・拡張子付き import・enum 禁止・未使用で落ちる）を守る。
- 依存は ui → infra → domain。`src/world/domain/` は何も import しない（型も自前で持つ。LatLng 程度は `../../map/domain/geo.ts` の型 import を可）。
- 外に送るのは検索の言葉だけ。URL は `https://msearch.gsi.go.jp/address-search/AddressSearch?q=<encodeURIComponent>`。
- 文言: ボタン「ワールドマップ」、検索欄「地名で探す」、帯「行った町 N ｜ クリア M」、出典「地名検索: 国土地理院」、失敗「探せませんでした」、見るだけの帯「👀 見ているだけ」＋2行目「<名前>・チェックインはできません」、戻る「📍 今いる場所に戻る」。
- ワールドマップの zoom は 4〜11、見るだけは 13〜17（`src/record/domain/view.ts` の MIN/MAX）。
- 終わりに `npm test`・`npx tsc -b`・`npm run lint` を通す。

## Review Focus
- 町が 0 件の人: ワールドマップは日本全体が出て、帯は「行った町 0 ｜ クリア 0」、落ちない。→ Task 5 にテスト。
- 検索の連打・入力途中: 古い返事が新しい返事を上書きしない（最後の言葉の返事だけ出す）。→ Task 3 にテスト。
- 地理院が壊れた JSON・空配列・座標の無い要素を返す: 落ちずに候補から除く／「探せませんでした」。→ Task 2・3 にテスト。
- 町の四角が読めない町（towns に行が無い・min/max が null）: 旗を出さないだけで、ほかの町は出る。→ Task 2 にテスト。
- 見るだけで位置の無い visit（lat/lng が null）: ピンに出さない。→ Task 6 にテスト。

### Task 1: domain（まとめ・四角・検索の読み取り）

**Files:**
- Create: `src/world/domain/cluster.ts`, `src/world/domain/box.ts`, `src/world/domain/gsi.ts`
- Test: 同名の `.test.ts`

**Interfaces (Produces):**
- `type TownMark = { id: string; name: string; cleared: boolean; lat: number; lng: number }`
- `type Group = { x: number; y: number; members: TownMark[] }` と `clusterMarks(points: { mark: TownMark; x: number; y: number }[], radiusPx: number): Group[]` — 画面の座標で、半径 radiusPx 以内を貪欲にまとめる（入力の順で先に来た点を核に）。group の x,y は member の平均。
- `type Box = { minLat: number; maxLat: number; minLng: number; maxLng: number }`、`boxCenter(b: Box): { lat: number; lng: number }`、`zoomForBox(b: Box, widthPx: number, heightPx: number, min: number, max: number): number` — 512px タイル基準で四角がちょうど入る zoom を min..max に収める。
- `type Place = { title: string; lat: number; lng: number }`、`parsePlaces(json: unknown, limit: number): Place[]` — 地理院の配列 `[{ geometry: { coordinates: [lng, lat] }, properties: { title } }]` を読む。数値でない座標・title の無い要素は捨てる。配列でなければ `[]`。

- [ ] **Step 1: テストを書く**: `clusterMarks` — 3 点のうち 2 点が 10px、1 点が 200px 離れているとき radius 40 で group 2 つ（members 2 と 1）。`zoomForBox` — 0.01°四方の四角・390×844 で 13〜17 に収まる値、日本全体級の四角で min に張り付く。`parsePlaces` — 正常 2 件、`null`、`{}`、座標が文字列の要素混じり、limit 8 で切れる。
- [ ] **Step 2: 失敗を確認**: `npx vitest run src/world/domain` → FAIL
- [ ] **Step 3: 実装**
- [ ] **Step 4: 通る**: `npx vitest run src/world/domain` → PASS
- [ ] **Step 5: コミット** `world: domain (clustering, box zoom, GSI parse)`

### Task 5: ワールドマップの画面 `WorldMap`

**Files:**
- Create: `src/world/ui/WorldMap.tsx`、`src/world/ui/WorldMap.test.tsx`

**Interfaces:**
- Consumes: Task 1〜4。`TownIcon`（`src/towns/ui/TownIcon.tsx`）、テーマ（`STYLE_URL`・`MAP_THEME`・`THEMES`・`pickTheme`・`themeStyle`。`RecordMap.tsx` の作り方にならう）、`maplibreWorker.ts` の import。
- Produces: `WorldMap({ towns, onClose, onOpen, loadBoxes? }: { towns: TownProgress[]; onClose: () => void; onOpen: (t: { name: string; center: LatLng; zoom: number }) => void; loadBoxes?: (ids: string[]) => Promise<Map<string, Box>> })`
- 全画面。MapLibre（zoom 4〜11、初期は日本全体 center [137.5, 37.6]・幅に合わせた zoom、回転なし）。遠くでは道・境界・文字のレイヤーを消す（見本の `main.tsx` と同じ選び方）。
- 町の印は HTML マーカー。`move` のたびに画面座標を出して `clusterMarks(…, 44)`。1 件なら旗（クリア＝橙、途中＝うす茶）＋町名の札、2 件以上なら数の丸。旗を押す → `onOpen({ name, center: boxCenter, zoom: zoomForBox(box, w, h, 13, 17) })`。丸を押す → その丸へ zoom +2 の easeTo。
- 上に `PlaceSearch`（onBack=onClose、onPick → `onOpen({ name: place.title, center, zoom: 15 })`）。下に帯「行った町 N ｜ クリア M」（N = towns.length、M = clearedAt != null の数）。
