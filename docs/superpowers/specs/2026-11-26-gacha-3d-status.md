## 1. 道具と流し方（共通の台本 `art/characters/_animal2/scripts/`）
- blender: `/home/otosa/tools/blender/blender-4.2.3-linux-x64/blender`。cwd はキャラのフォルダ、`$B -b -P ../_animal2/scripts/<段>.py -- config.json`。
- 流す順: `refcolors.py` → `stage2.py`（塗り直し）→ `stage3.py`（骨と重み）→ `pose3.py`（試しの姿勢、CAPTURE=1 で撮影）→ `range5.py`（関節ごとの破れない上限を測る）→ `stage4.py`（顔 4 こま）→ `stage5.py`（動き 4 つ、`work/avatar.glb` を出す）→ **`cp work/avatar.glb avatar.glb`** → `python3 ../_animal2/scripts/gate6.py .`（**Blender ではなくふつうの python3**）→ 撮影。
- 撮影: `art/characters/_animal2/scripts/cap.sh "glb=/art/characters/<キャラ>/avatar.glb&what=<shots|grid4|video4>&..." <出力フォルダ>`。
  - shots: `&s=名前:yaw:elev:px:見える高さ:x:y(高さ):z(前 +)` を `;` でつなぐ。顔の拡大の例 `front:0:5:400:0.3:0:0.65:0.2`。
  - video4: `&px=600` → コマ `v-0000.png…` → `ffmpeg -framerate 30 -i v-%04d.png -c:v libx264 -pix_fmt yuv420p -crf 20 gate/gate6-motions-600.mp4`。
  - **撮影は キャラのフォルダの `avatar.glb` を読む。stage5 は `work/avatar.glb` を書く。写し忘れると古い模型を撮る**（11-26 にこれで直しが反映されていないのに気づかず、鼻の直しを 2 回ムダにした）。
- 関門 1 の数: `art/characters/01-hoshifuru-kirin/scripts/gate1-probe.py`（キリン用。腕のすき間・足・輪郭は使える。腕の内側の色・首の細さ・角・tail_found は動物には当てはまらない）。撮影は各キャラの `gate1/views.sh`。
- `probe.py` の `tail_join` は config の `tail_probe_z` の高さから測る。しっぽの形が変わったら値を直さないと意味のない数字になる（ねこの arms4 版で外れた）。
- ComfyUI: オーナーが Windows で起動しておく（`cd D:\mogumo-3d\ComfyUI; D:\mogumo-3d\venv\Scripts\python.exe main.py --disable-pinned-memory`）。WSL からは 127.0.0.1:8188 に直接届かないので、**`powershell.exe` 経由**で: 入力の絵は `cp … /mnt/d/mogumo-3d/ComfyUI/input/`（サンドボックスの外）、実行は `cd /mnt/c && powershell.exe -NoProfile -Command "cd D:\mogumo-3d; foreach (\$s in 123,456,789) { venv\Scripts\python.exe tools\run_char_mv.py <名前> \$s <接頭>\$s }"`。後ろの絵なし版は `tools\run_char_mv_noback.py`（背中のリュックが消えるので使わない）。出力 `/mnt/d/mogumo-3d/ComfyUI/output/mogumo/<名前>_<ラベル>_{shape,textured}_00001_.glb`。1 つ約 4 分。
- 入力の絵: `blender -b -P art/prototypes/avatar/prep-ref.py -- <絵> <出力> [shadow] holes`（`holes` で、しっぽの輪の内側など囲まれた背景も消す）。

### 14 クッキーくま — 段 6 まで（顔の直し途中）
- 形 種 456。設定 `art/characters/14-cookie-kuma/config.json`。
- 11-26 のオーナー指摘と対応:
  1. 「くまの口元じゃない。しばを使ってない？」→ しばの五角形の鼻・ω の口のままだった。**くま自身の元の絵（`ref/arms2-front.png` の目の下）から測って描き直した**: 鼻 = 横長のだ円（`face.nose.shape: oval`、色 147,83,57）、口 = 浅い ω の細い線（`face.mouth_color` 160,98,98、`mouth_box`、`mouth_w` 0.5）、口元 = ふちをぼかしたクリーム（`face.muzzle`）。
  2. ほほがまだら → 区分けのほほを毛にして（規則の `to` を fur に）、顔で丸いピンクを描く（`face.blush`）。
  3. 「目元がえぐれている・鼻の凹凸」→ 生成の形の目がくぼみ、鼻がふくらんでいた。`face.flatten`（だ円の外の輪の点に 2 次曲面を当てはめ、中の点の奥行きをそろえる。ふちは `flatten_blend` 倍まで元へ戻す）。いまの値 `[[-0.1125,0.669,0.06,0.062],[0.1194,0.669,0.06,0.062],[0.0034,0.632,0.04,0.032]]`・blend 1.3。広げた版（0.066 / 0.045・blend 1.6）は目と鼻の範囲が重なって筋と段が出た。
- **オーナー「目のえぐれは直したい」→ 未完**。残り: 斜めから右目のまわりにうっすら輪、鼻の上に薄い弧。次の手: ① 先に形のくぼみの範囲を測る（目のまわりの点の奥行きの差の地図）→ 目のだ円をくぼみの大きさに合わせる、② 目と鼻の当てはめの輪が重ならないようにする（鼻を先にならしてから目、または輪から相手の範囲を外す）、③ それでも輪が残れば、ならした所と外の境を数 mm ずつなめらかにする。
- 元の絵との違い（未対応・オーナーに聞いたまま）: 目の下半分の明るい茶のグラデーション、口の両はしの巻き上がり。
- 走りの歩幅は上限に合わせて 1 割縮めた（0.018）。gate6 合格。
