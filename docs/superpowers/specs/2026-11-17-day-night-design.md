# A14 昼と夜 設計

状態: 決定（オーナー）・実装済み／2026-11-17

## 決めたこと（オーナー 2026-11-17）
- **切り替えの基準: 日の入り・日の出（案A）**。今いる場所で計算（場所が分かるまでは自宅、無ければ東京）。夜 = 日の入りから次の日の出まで。計算は NOAA の簡易式（`src/daynight/domain/sun.ts`、日本で誤差数分）。
- 設定の「いつも昼／夜」スイッチは作らない（頼まれていない）。試すときは URL の `?night`・`?day`（そのタブを閉じるまで固定）、`?auto` で固定をやめる。
- 確かめるのは、起動時・アプリに戻ってきたとき・1 分ごと。途中で切り替わったら、地図を作り直さずに色だけ替え（`recolor`）、雲・3D の光・BGM（1.5 秒で消して、もう片方の曲をふわっと）も替える。

## 夜の見た目（iPhone で見ながらオーナーと決めた）
- 地図: イラスト調の夜の色 `illustNight`（紺の地面・青紫の建物。道は紺の仲間で少し明るいだけ。黄色の道は「浮く」のでやめた。地面と建物は 1 段暗く）。メインの地図・記録・ワールドマップ・見るだけの地図で共通（`currentTheme`）。
- 霧の雲: 月明かりの淡い青紫、下の影は深い紺。
- 3D（お店・施設・アバター）: 月明かりの光（アバターもまわりと同じ暗さ）。もともと光る材質（窓・提灯）を強く、光る窓が無い模型（ラーメン・ベーカリー・洋食）はガラスの水色を暖かい明かりに。
- お店の足元の光: 地面に暖かい光のたまり（お店の幅の 2.4 倍・濃さ 0.85・足し算で重ねる）。
  - 絵（テクスチャ）を貼ると iPhone で色つきの点々が出た（地図と描画のしくみを共有しているため、地図の側の絵を読んだと考えている）ので、計算で描く。
  - 3.0 倍は重かった。地図の円の層で描く案は、足し算ができず見た目が違うのでやめた。
- BGM: 夜は夜の曲（v1、`src/assets/sound/bgm/night.m4a`）。
