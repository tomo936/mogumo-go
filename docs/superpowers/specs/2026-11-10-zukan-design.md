# 図鑑（ジャンル別・シールアルバム風）設計メモ

- 日付: 2026-11-10
- 決定: オーナー（「2で」＝ジャンル別のページ／「チェックインしたのは全部、あとは見つけた未訪問は『？』」）
- 仕様の元: SPEC S11（お店カードの図鑑）、S14（自分の写真は詳細側に後で）、S17（図鑑は6画面の1つ）

## 意図
行ったお店をカードとして集め、ジャンルごとのページに「シールを埋めていく」楽しさを出す。まだ行っていない店は、名前を伏せたシルエットで「まだ埋まっていない」ことを見せる。

## 決めたこと
- **並べ方**: ジャンル別のページ（18種類）。ページを左右に送る。上にジャンルの小さな見出しとシールの数（例: ラーメン 3/7）。
- **カードの中身**
  - 行った店: ホットペッパーの写真（無ければ種類の絵）、店名、行った回数、枠（ふつう／銀／金。お店のシートと同じ）。
  - 行っていない店: 名前は伏せる。シルエット（灰色）と、キャッチの一言だけ（キャッチが無ければ種類だけ）。
- **タップ**: 行った店・行っていない店とも、お店のシートと同じ画面を開く（行っていない店は、シートの名前も伏せる＝気配と同じ扱い）。
- **入口**: 探索シートの「図鑑」（S17）。
- **データ**: `shops` テーブルに、見つけたお店（ホットペッパー・地図）が入っている。その中から、ページに並べる。記録は `checkins`（自分の行だけ）を、今の `loadProgress` と同じ方法で読む。

## 私の判断（確認してほしい）
1. **行ったお店は全部出す。見つけたけど行っていないお店は「？」で出す**（オーナー決定 2026-11-10）。「？」は灰色のカードで、ジャンルの絵とキャッチの一言だけ。名前は出さない。一度も見つけていないお店は出さない（全部の店は分からないため）。
2. **並ぶ順**: 行った店を先、その中は最近行った順。未訪問は後ろで、近い順。
3. **1ページのカード数**: 3列×4段（12枚）。
4. **自分の写真**: 今回は入れない（S14 の詳細で後から）。
5. **写真が無い店**: 種類の絵（お店のシートと同じ）。
