# 気配・デイリー 公開（デプロイ）の手順（本人用）

アプリ側はもう開発用のサイト（`mogumo-go-dev.vercel.app`）に入っています。気配を実際に動かすには、Supabase の **開発用プロジェクトに、SQL（0004）と関数2つを置く** 必要があります。下の順に進めてください。

> **重要: 必ず開発用プロジェクト `mogumo-go-dev` で作業してください。本番のプロジェクトは使いません。** 画面の上のほうのプロジェクト名が `mogumo-go-dev` になっていることを、毎回確かめてください。

> **手順2と3は続けて行ってください。** 2 を流してから 3 で `checkin` を置き直すまでの間は、チェックインが失敗します（その間はチェックインを試さない）。

## 0. 反映の前に（いまの状態の確認）
1. iPhone で開発用のアプリを開く。
2. お店のチェックインが今までどおり **+30** で通ることを確かめる（気配の仕組みがまだサーバーに無くても、アプリは壊れない）。
3. 画面下の「探索」を押すと、シートに「気配を読み込めませんでした」と出れば OK（サーバーがまだなので正しい）。

## 1. 開発用プロジェクトを開く
1. ブラウザで Supabase（supabase.com）にログインする。
2. プロジェクト一覧から **`mogumo-go-dev`** を選ぶ。

## 2. SQL（0004）を流す
1. 左のメニューから **SQL Editor** を開き、**New query** を押す。
2. パソコンで `supabase/migrations/0004_daily_hints.sql` を開き、**中身を全部コピー**して貼る。
3. **Run** を押す。「Success」と出れば OK（何度流しても大丈夫な作りです）。
4. 赤いエラーが出たら、文面をそのまま Claude Code に見せる。**すぐ手順3へ。**

## 3. 関数 `checkin` を置き直す（ファイルが1つ増えます）
1. 左のメニューの **Edge Functions** で、一覧の **`checkin`** を開き、コードの画面（Code / Editor）を開く。
2. `index.ts` を、`supabase/functions/checkin/index.ts` の中身に全部貼り替える。
3. `core.ts` を、`supabase/functions/checkin/core.ts` の中身に全部貼り替える。
4. **ファイルを足す**（Add file）。名前は **`osmTile.ts`**。`supabase/functions/checkin/osmTile.ts` の中身を全部貼る。
5. **Verify JWT** がオンのまま **Deploy**。

## 4. 関数 `daily-hints` を新しく置く
1. **Edge Functions** → **Deploy a new function** → **Via Editor**。
2. **先に、関数の名前を `daily-hints` に変える**（変えないと仮の名前で置かれます）。
3. `index.ts` に `supabase/functions/daily-hints/index.ts` の中身を貼る。
4. ファイルを足して `core.ts`（`supabase/functions/daily-hints/core.ts`）と `osmTile.ts`（`supabase/functions/daily-hints/osmTile.ts`）を貼る。3つそろっていることを確かめる。
5. **Verify JWT** がオン。Secrets（キー）は何も足さない（この関数はホットペッパーを呼びません）。
6. **Deploy function**。

## 5. iPhone で確かめる
1. アプリを開いただけでは気配が作られない（「探索」の数字が出ない／シートを開くまで作られない）。
2. 「探索」を押すと、シートに今日の気配が最大3件。店名は「？？？」。
3. 閉じて開き直しても同じ3件。
4. 気配をタップ → カメラがその場所へ動き、ヒントのシート（ジャンル？・キャッチの断片・予算・ここから 約○m）。
5. 電車・車の中で初めて開くと「降りたら今日の気配が出るよ」。
6. 今日の気配から 1.5km 以上離れると「この辺りで探し直す」が出て、押すと作り直される（1日1回だけ）。
7. 気配のお店の 30m 以内に入ると「気配の正体は…『○○』！」。
8. 気配のお店でチェックインすると **+40**（帯に「気配ボーナス +10」）。30〜50m で伏せたままチェックインすると、演出の中で正体が出る。
9. 次の日（日本時間 0時を過ぎてから）に開くと、新しい気配に入れかわる。
10. 気になったことは、画面を撮って Claude Code に送る。
