# A5 ポコタンの案内（初めての人へのチュートリアル）設計

状態: 決定（オーナー OK）・実装済み／2026-11-17

## ねらい
初めての人が、地図・霧・チェックイン・気配・記録の遊び方を、ポコタンとの会話で楽しく覚える（SPEC §12 A5「恋愛ゲームのような雰囲気」）。

## 決まっていること（オーナー）
- レイアウトは **案A ノベル型**（`art/prototypes/pokotan-guide/layouts-v1.png`）。下にセリフの窓、左上に大きなポコタン、説明する所だけ丸く明るく抜く、タップで次へ。【2026-11-17】
- ポコタンは **Live2D** で、ゆらゆら揺れて、しゃべる間は口パク。セリフの語尾は「〜ポコ！」、明るい口調。【2026-11-17】
- 見た目は本人のオリジナルキャラ（白いキリン・カラフルな水玉・ピンクのしっぽ）。モデルは枝 `origin/add-pokotan-live2d` の `public/live2d/poko/`。
- 公開は **個人**。Live2D の出版許諾契約（売上 1000 万円以上の事業者だけが必要）は要らない。【2026-11-17】

## 出し方
- 初期設定を終えて、初めて地図に入ったときに出す。終わるかスキップしたら、端末に `mogumo.tutorial.<userId>` を保存し、もう出さない。
- ログインボーナスは案内のあとに出す（案内中は出さない）。
- 設定の「サポート」の「遊び方をもう一度見る」（小さく「ポコタンが案内します」）。押すと地図に戻って最初から。案内のあとのログインボーナスは 0.4 秒で出す。

## 画面（案A）
- 全体を少し暗くして、説明している部品のところだけ丸く抜く。抜くのは「？」の雲・下の丸いボタン・左上のキャラとコインの 3 か所だけ。霧・チェックイン・晴れるのページは指せる部品が無いので抜かない（2026-11-17 オーナー「指す円はいらないのでは」）。
- 下: クリーム地・茶色の線の窓（他の手帳風のシートと同じ色）。左上に「ポコタン」の札、本文は 1 文字ずつ（40ms/字の一定の速さ。口に合わせて変えない）、出きったら ▼ がはねる。
- 窓の左上に Live2D のポコタン（高さ およそ画面の 1/3）。
- 右上に「スキップ」。
- タップ: 文字が出ている途中 → その文を全部出す／出きっている → 次へ。最後のページで閉じる。
- 音: 次へ進むたびにいつもの「ぽこっ」（全ボタン共通のしくみをそのまま使う）。

## セリフ（9 ページ。2026-11-17 オーナー添削: 霧は歩くとではなくチェックインで晴れる・目標は町のクリア・ガチャでキャラを変えられる（ガチャは未実装だが言い切る＝案A））
1. あいさつ（抜き無し）: 「ナビゲーターのポコタンポコ！ この町のおいしいお店、いっしょに探しに行くポコ！」
2. 霧（自分のまわり）: 「まわりのもこもこは霧ポコ。霧の中のお店は、すぐ近くまで行かないと見えないポコ！」
3. チェックイン（自分のまわり）: 「お店に着いたら、建物をタップしてチェックインするポコ！ 50m 以内ならできるポコ！」
4. 晴れる（自分のまわり）: 「チェックインすると、まわりの霧がパーッと晴れるポコ！ 晴れた場所のお店は、ぜんぶ見えるようになるポコ！」
5. 目標（抜き無し）: 「目指すのは町のクリアポコ！ 町のお店の半分に行くと、町じゅうの霧がいっぺんに晴れるポコ！」
6. 「？」の雲: 「上の「？」の雲を押すと、霧の中にかくれたお店の気配がわかるポコ。探しに行ってみるポコ〜！」
7. 下の丸いボタン: 「下の丸いボタンからは、図鑑や記録が見られるポコ。行ったお店がどんどんたまっていくポコ！」
8. 左上のキャラとコイン: 「たまったグルメコインでガチャを引くと、新しいキャラが仲間になるポコ！ 左上から、お気に入りのキャラに変えられるポコ〜！」
9. しめ（抜き無し）: 「準備ばっちりポコ！ まずはこの町のクリアを目指して、出発ポコ！」

## Live2D の入れ方
- Core（`live2dcubismcore.min.js`、約 230KB）・モデル・シェーダーは枝の `public/live2d/` をそのまま持ってくる。
- Cubism Web Framework は公式 GitHub `Live2D/CubismWebFramework`（5-r.5、コミット d4da0aa。ぽこポケの写しと中身が同じことを確認）を rolldown で 1 つの JS（約 195KB・gzip 39KB）にして `src/vendor/live2d-framework/` に置き、使う分だけの型を手書きの `.d.ts` にした（Framework は enum・namespace を使うため、そのままでは `erasableSyntaxOnly` で落ちる）。npm のパッケージは足さない。シェーダーは公式と同じことを確認。
- 案内を開いたときだけ Core と Framework を読み込む（いつもの地図は重くならない）。
- 動き: 待機の揺れ・呼吸・まばたき（`PokoModel.js` を参考）。口（`ParamMouthOpenY`）は字の出方に合わせて 2 字ごとに開け閉めし、区切りの間と出きったあとは閉じる（2026-11-17 オーナー「口数が合っていない」）。
- 先読み: 案内がまだの人は、タイトルの読み込みの中で、お店がそろったあとに Core・Framework・モデルを読む（最大 8 秒待つ）。そのあと「タップしてスタート」。案内は地図に入って 3.2 秒後（オーナー「出るのが遅い」「最初にお店が出ない」「タイトルでの読み込みの時にするべき」）。
- Live2D が読めない端末では、ポコタンの静止画（`src/assets/guide/poko.webp`、Live2D の描画を撮った 1 枚）で続ける。
- ライセンス表示: 設定の出典に「Live2D Cubism」を足す。

## 作らないもの
- ポコタンをタップしたときの反応、表情の差分（モデルに無い）、音声。
- 案内中に実際に操作させる形（見せるだけ）。

## 置き場所
- `src/guide/`（domain: ページの一覧と進め方・抜く場所の計算、infra: Live2D の読み込みと描画、ui: 画面）。
