# 最初の1周（PDCAサイクル1）Plan

対象は「全機能を一通り入れた動くアプリ」。仕様の正本は SPEC.md。
進め方の訂正: 当初「1機能＝1周」としていたが、正しくは **1周目で全機能を入れて、2周目から改修**。この周の中では小さく積む順番を守るが、周の完了条件は「全機能が一通り動くこと」。

## 目的
もぐもGO の全機能を一通り実装し、実機で通しで遊べる状態にする。以後の周は、この土台の改修・改善に充てる。

## スコープ（作るもの：全機能）
- 土台: Vite＋React＋TypeScript、MapLibre GL JS＋OpenFreeMap、Vercel 配信（PWA対応）
- 地図: 自宅（経堂）周辺を pitch 55°で傾け表示。スタイルは世界観「明るい昼のグルメ」寄せ
- アバター: 2Dスプライト4方向＋歩行アニメ、GPS（watchPosition）間を補間して滑らかに追従、検知サークル＋影
- お店データ: ホットペッパーグルメAPI連携（キーはサーバー側＝Supabase Edge Functions 経由）、現在地から1km以内のお店ピン（ジャンルアイコン付き。SPEC S1。自宅1kmは霧・クエストの探索範囲）【2026-11-05 SPEC に合わせて修正】
- 霧: グリッド管理（25mセル）。3層の晴れ方＝チェックインで店周り200m／自宅からのルート沿い（OSRM）／町制覇（町内店の半分以上）で町全体
- チェックイン: 店から50m以内で手動。カード入手・霧晴れ・ルート晴れ・町制覇カウント・週ミッションカウント・グルメコイン付与が連動
- 気配とクエスト: 毎朝、霧の中の未訪問店からデイリー気配3件（ジャンル曖昧表示＋個性ヒント、店名は30m以内で判明、ジャンル不明は「謎の気配」）。週ミッションは条件型で週3軒
- 図鑑: お店カードのコレクション（一覧＝公式画像、未訪問は店名伏せ＋霧。詳細で自分の写真をピン留め）
- 感想と星: ログインユーザー全員に公開【2026-11-05 決定】（ニックネーム表示、編集・削除可、写真1枚まで任意、通報＋管理者削除）
- 記録（開拓記）: 地図スナップショット＋数字（開始時点＝自宅設定の完了時点、サーバー保存）
- アカウント: Googleログイン（Supabase Auth）、ニックネーム（10文字まで・変更可）、自宅設定（現在地ボタン＋地図で微調整、正確な座標は端末内のみ）
- ガチャ: グルメコイン制の無料ガチャ（チェックイン30／気配店40／週ミッション・町制覇100、同じ店のコインは1日1回まで、1回100コイン・10連1000コイン、★3 70%／★4 25%／★5 5%、10連で★4以上1体確定、天井＝★5が出てから30回以内に★5確定、初期プール＝候補30体全員（排出はキャラのみ、衣装なし。SPEC §8）、ダブりはキャラ図鑑のレベル Lv1〜5 と光り方で表す、初回キャラは設定で男の子・女の子から選択）【2026-11-05 SPEC と当日の決定に合わせて修正】
- 共有: 図鑑カード画像と制覇・開拓マップ画像の2種（記念画像デザイン）

## 積む順番（この周の中の手順）
1. 土台作り: GitHub リポジトリ → Vite 雛形 → Vercel 接続（プレビューURL）
2. Supabase プロジェクト（東京リージョン）＋ Googleログイン ＋ 基本テーブル
3. 地図表示 → 傾け → 現在地追従 → アバター歩行
4. お店ピン（実データ）→ チェックイン → 霧グリッドと3層の晴れ
5. 気配・デイリー/週ミッション → 図鑑 → 感想 → 記録
6. ガチャ → 共有画像 → PWA仕上げ
7. 実機（iPhone 16）で通し確認

## 技術リスクと作法
- 地図の移動で React を再描画しない（地図とアバターは MapLibre のレイヤー／マーカー側で持つ）
- ピンは DOM で大量に置かない（レイヤー描画）
- スプライトは 1秒8コマのフレーム切り替え＋小さな上下動
- APIキーはブラウザに露出させない（Edge Functions 経由）
- Supabase 無料枠の自動バックアップ無しへの備え: ダンプ／書き出しスクリプトを用意する
- HTTPS でないと位置情報が取れない（Vercel のプレビュー URL で実機確認する）

## 受け入れ条件（Check の物差し）
1. iPhone 16 のブラウザで、地図のスクロール・ズーム・傾けが引っかからずヌルヌル動く
2. 実際に外を歩いて、アバターがブレずに歩行アニメでついてくる（GPS の飛びが補間でならされる）
3. 全機能が通しで動く: ログイン → 自宅設定 → 気配を選ぶ → 歩いて到着 → チェックイン → 霧が晴れる → 図鑑に残る → コインでガチャが回る
4. 無料枠の範囲で動いている（API・転送量が想定内）
