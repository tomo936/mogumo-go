# 甘味・洋菓子のお店がアプリに出ない問題の調査と設計

状態: 未対応
日付: 2026-11-28
依頼元: ギルベルト（オーナー承認済み）

## ゴール（オーナーの要望）

浅草九重や経堂の亀屋のように、実在する甘味・洋菓子のお店がアプリに出てきません。こうした店が、地図・図鑑・チェックインの対象として出るようにしたいです。

## 進め方

- 原因の調査と設計は、Claude自身で行ってください。
- 末尾のギルベルト調査メモはあくまで参考です。前提にせず、裏取りし直して構いません。結論が食い違う場合は、そちらの裏取りを正としてください。
- 影響の大きい案（データの取り方を根本から変える等）が出たら、判断ボード（BOARD.md）に積んでください。

## 参考: ギルベルト調査メモ（2026-11-28、参考扱い）

- 経堂駅1km圏: OSMの飲食店（名前あり）178店のうち、OpenFreeMapタイルのpoiに無いのは5店（shop=pastry 4店: RARASAND / ARPAJON / 亀屋 / ICHIMAN、shop=tea 1店: 芳香園）。
- 浅草1km圏: 704店中6店（pastry 2、tea 2、restaurant 2。restaurantの2店が無い理由は未確認）。
- 京都駅1km圏: 361店中6店（pastry 3、tea 1、pub 1、restaurant 1。pub・restaurantの理由は未確認）。
- OpenMapTiles の layers/poi/mapping.yaml の shop 一覧に pastry と tea が無いことを確認しました（bakery / confectionery / deli / coffee / alcohol / chocolate はあります）。タイル側の実測でも、経堂周辺4タイルで pastry は0件でした。
- 参考案（ギルベルト案・前提にしないこと）: 土台はタイルのまま、pastry・teaだけOSMから直接（Overpass）取って補い、サーバー側で shops に貯める形。ただしOverpassは共用で遅く回数制限があるため、端末が毎回叩く形は避ける前提です。
- 分類の受け皿の想定: pastry・tea は既存の「スイーツ（cake）」に振る案。

## 範囲外（別件として切り分け）

- パン工房 KIMURAYA（世田谷区宮坂3-19-2）: OSM自体に未登録でした（Googleマップには掲載あり）。アプリではなくデータ登録側の問題です。今回の調査・設計の対象には含めないでください。
- deli / coffee / alcohol（惣菜・コーヒー豆販売・酒屋）を対象ジャンルに入れるかは未決定です。今回の範囲外とします。
