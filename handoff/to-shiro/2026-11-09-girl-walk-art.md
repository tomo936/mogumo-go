# 女の子の歩く絵（8方向）（Claude Code から、ミシェーラへ）

- 日付: 2026-11-09
- 依頼の理由: 地図の上を歩くアバターを、まず男の子の絵でお試し版として入れている（オーナー決定 2026-11-09）。初回設定で女の子を選んだ人のために、女の子の歩く絵がほしい。以前チャットで頼んだまま（`handoff/` を始める前）で、依頼ファイルが無かったので改めて出す。

## ほしいもの（男の子 `art/characters/boy-walk/` とそろえる）
- キャラ: 初回設定の女の子（立ち絵 `src/assets/characters/starter-girl.webp`）と同じ子・同じ服。
- 向き: 8方向。front（手前向き）・front-left・left・back-left・back（奥向き）・back-right・right・front-right。
- コマ: 1向き 21コマの歩くループ（男の子と同じ数・同じ長さ・同じ歩幅の感じ）。1コマ目は立ち姿に近い形（止まったときに使う）。
- 大きさ: 1コマ 245×472 px（男の子と同じ）、足元の位置も男の子とそろえる。背景は透明 PNG。
- 画風: 男の子の歩く絵と同じ（線・影・色味）。
- 置き場所: `art/characters/girl-walk/<向き>/frame-01.png〜frame-21.png`（画像本体をセッション経由で送る場合は Claude Code が置く。送るときは、Claude Code が作業していない時に、向きの名前を添えて数枚ずつ）。

## 補足
- 届いたら、アプリ用に縮めた並び絵を作り、初回設定で女の子を選んだ人に出す。
